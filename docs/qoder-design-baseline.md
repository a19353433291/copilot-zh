# Qoder 设计基准（实测存档）

> 数据来源：2026-11-12 对 Qoder CN 主界面窗口的 PrintWindow 截图（1984×1207，DPR 1.5）
> 截图存档：`docs/images/_baseline-qoder.png`（有效状态）
> 注意：Qoder 重新加载后窗口会变空白，务必用存档图做基准

## 一、颜色（像素采样，非 CSS 推测）

| 区域 | 色值 | 说明 |
|---|---|---|
| 侧栏底色 | `#f6f6f6` | rgb(246,246,246) 纯中性 |
| 内容区底色 | `#ffffff` | 纯白 |
| 侧栏/内容分界 | `#e6e6e6` | 单像素 |
| 卡片/标签底 | `#ededed` | rgb(237,237,237) |
| 强调色 | `#4b6f5a` | 墨绿，**全界面仅发送按钮使用** |

**关键结论**：默认界面是纯中性灰阶，不是暖绿色系。
CSS 里的 `#f4f5f3`/`#d5dbd8`（微绿调）属于可选皮肤，不是默认。

## 二、量化指标（DPR 归一化后）

| 指标 | Qoder | 汉化助手（改造前） | 说明 |
|---|---|---|---|
| 灰阶纯度 | 98.5% | 80.4% → 99.4% | 已对齐 |
| 纯背景占比 | 92.0% | 77.2% | 差距 15% |
| 边缘强度 | 0.77 | 1.42 | 差距 85% |
| 最长空白带 | 12px | 1px | 差距 12 倍 |
| ≥8px 空白带数 | 2 | 0 | 缺少呼吸间隙 |
| 暗色文字占比 | 0.31% | 1.23% | 文字密度 4 倍 |

## 三、设计 Token（从 CSS 提取）

### 圆角
```
--radius-xs  2px    --radius-sm  4px    --radius-md  6px
--radius-lg  8px    --radius-xl  12px   --radius-2xl 16px
```
主流用 4-8px，12px 只用于大面板。

### 字号（使用频次）
```
12px 15次 | 13px 14次 | 11px 7次 | 14px 7次 | 16px 5次
```
与我们当前体系几乎相同。

### 间距
```
8px 6次 | 12px 2次 | 10px 1次 | 6px 1次
```
8px 是绝对基准。

### 高度
```
20px(标签) | 26px(紧凑按钮) | 38px(标准按钮) | 42px(输入框) | 52px(顶栏)
```

### 动效
```
75ms / 100ms / 120ms / 140ms / 150ms / 200ms / 300ms
主流 150ms
```

## 四、技术实现特征

| 项目 | 数值 | 说明 |
|---|---|---|
| `color-mix()` | 454 次 | 几乎不用 rgba()，透明度跟随主题色 |
| `oklch()` | 2 次 | 未全面转向 oklch |
| `backdrop-filter` | 37 次 | 但都是 1-2px 极轻模糊，不是大模糊 |
| `linear-gradient` | 93 次 | 多为 1px 分隔线的渐变柔化 |
| 主题机制 | `data-theme` 180 次 | 6 套皮肤 × 深浅 |

侧栏宽约 19.7% 窗口宽（390/1984）。

## 七、待改进项（按差距排序）

1. **纯背景占比** 77% vs 92% — 每屏元素太多，需要减少信息密度
2. **边缘强度** 1.42 vs 0.77 — 文字/线条对比偏硬
3. **空白带** 1px vs 12px — 缺少元素间的真实间隙
4. **暗色文字密度** 1.23% vs 0.31% — 同上，信息密度问题

前两项可通过调整样式改善，后两项是**信息架构层面**的问题。
